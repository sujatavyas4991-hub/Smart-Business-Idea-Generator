# 💡 Smart Business Idea Generator

## ⚡ Quick Start

```bash
git clone https://github.com/sujatavyas4991-hub/Smart-Business-Idea-Generator.git
cd Smart-Business-Idea-Generator/smart_business_idea_generator
pip install -r requirements.txt
cp env.example .env        # add your IBM watsonx.ai credentials
python app.py              # open http://localhost:5000
```

## 🤖 Tech Stack

| Layer | Technology |
|-------|-----------|
| LLM | IBM Granite 3.3-8B Instruct (watsonx.ai) |
| Backend | Python 3.9+ · Flask 3 · Gunicorn |
| Frontend | HTML5 · Chart.js · Vanilla JS |
| Multi-Agent | 7 custom agents (RAG, Trend, Idea, Feasibility, Refinement, Roadmap, Ethics) |
| Multimodal | Image upload · Voice recording · Audio transcription |
